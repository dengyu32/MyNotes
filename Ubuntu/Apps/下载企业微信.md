### 安装 Deepin Wine 环境

>   企业微信依赖 Deepin Wine 提供的 Windows 兼容层，需要先安装运行环境

#### 从源码安装（可选）

>   手动安装 Deepin Wine 组件，适合需要定制环境的情况

```
git clone https://gitee.com/wszqkzqk/deepin-wine-for-ubuntu.git
cd deepin-wine-for-ubuntu/
./install.sh
sudo apt-get install libjpeg62:i386
```

#### 一键安装 Deepin Wine（推荐）

>   推荐使用维护团队提供的自动化脚本，安装最完整的运行环境

```
wget -O- https://deepin-wine.i-m.dev/setup.sh | sh
```

终端提示示例：

```
微信：sudo apt-get install com.qq.weixin.deepin
QQ：sudo apt-get install com.qq.im.deepin
TIM：sudo apt-get install com.qq.office.deepin
钉钉：sudo apt-get install com.dingtalk.deepin
完整列表见 https://deepin-wine.i-m.dev/
```

>   建议安装完成后注销或重启一次，以正确加载 Deepin Wine 运行环境。

#### 可能遇到的依赖冲突

>   某些系统环境可能出现 libsane 冲突，需要手动调整版本

```
sudo apt purge libsane
sudo apt install libsane1=1.2.1-5deepin1+rb1 libsane-common=1.2.1-5deepin1+rb1
sudo apt-mark hold libsane1 libsane-common
```

### 安装企业微信

>   使用 Deepin 仓库提供的企业微信包直接安装

```
sudo apt update
sudo apt install com.qq.weixin.work.deepin
```

>   第一次运行会初始化 Wine 容器，时间较长属于正常现象。

------

#### 修复启动报错（解压失败）

>   某些版本的启动脚本会因解压失败导致无法启动，需要手动补丁

编辑文件：

```
/opt/deepinwine/tools/run_v4.sh
```

修改内容：

```
# 原始
7z x "$APPDIR/$APPTAR" -o"$1"

# 修改为
7z x "$APPDIR/$APPTAR" -o"$1" || true
```

>   添加“|| true”可避免解压异常阻断启动流程。

------

### 启动企业微信

>   可通过命令或桌面图标启动

```
deepin-wine com.qq.weixin.work.deepin
```

如遇缺少 32 位库提示：

```
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install libjpeg62:i386 libpng12-0:i386
```

### 原理与安全性

#### 为什么显示 Windows 界面？

>   企业微信是 Windows 应用，通过 Wine 运行，因此界面一致

-   Deepin Wine 提供 Windows API 兼容层
-   负责将 Win32 调用转换为 Linux 系统调用
-   并非模拟器或虚拟机，性能开销极低

#### Wine 的工作原理

>   Wine 通过兼容层方式执行 Windows 程序，不需要 Windows 系统

**基本机制：**

-   提供类似 Windows 的文件系统和注册表
-   通过兼容层翻译 Windows API 调用
-   程序实际运行在 Linux 环境中

与虚拟机对比：

-   不需要 Windows 镜像
-   资源开销更小
-   可直接访问 Linux 文件系统

#### 安全性分析

>   安全性主要取决于应用来源与 Wine 仓库的可靠性

-   企业微信本身由腾讯提供
-   Deepin Wine 若来源不可信，可能带来未知风险
-   推荐使用可信源 `deepin-wine.i-m.dev`

#### Wine 容器与隔离策略

>   每个应用运行在独立的 Wine 前缀目录中

默认目录：

```
~/.deepinwine
```

**潜在风险：**

1.  依赖库冲突（尤其是 32 位库）
2.  权限与当前用户一致，可访问家目录

**隔离建议：**

-   为不同应用使用独立 Wine 前缀
-   不要共用 Wine 容器避免冲突

### 卸载企业微信与 Deepin Wine

#### 卸载软件包

>   移除企业微信与相关 Deepin Wine 组件

```
sudo apt remove --purge \
    com.qq.weixin.work.deepin \
    deepin-wine10-stable \
    deepin-wine-helper \
    deepin-app-store-runtime \
    dde-qt5integration \
    libdtkcommon libdtkcore5 libdtkgui5 libdtkwidget5 \
    libodbc1 libosmesa6 libqt5xdg3 libqt5xdgiconloader3 qt5dxcb-plugin libcapi20-3

sudo apt autoremove --purge
sudo apt autoclean
```

>   若你还有其他 Deepin Wine 应用，请谨慎删除依赖。

#### 删除 Wine 容器

>   清理运行数据和注册表

```
rm -rf ~/.deepinwine
sudo rm -rf /opt/deepinwine
```

#### 删除软件源

>   移除 Deepin Wine 软件源并刷新缓存

```
sudo rm /etc/apt/sources.list.d/deepin-wine.list
sudo apt update
```

#### 可选：恢复系统原生库

>   如曾修改 libsane，可恢复为系统默认版本

```
sudo apt-mark unhold libsane1 libsane-common
sudo apt install --reinstall libsane1 libsane-common
```
