### 配置 C++20 开发环境

>   本笔记整理了在 Ubuntu 系统下安装和配置 C++20 编译环境，并在 VSCode 中配置 clangd/clang-tidy 的方法。

------

#### 1. 安装 build-essential

```
sudo apt install build-essential
```

>   安装完成后，检查 `/usr/bin/` 下是否存在 `gcc`、`g++`、`gcc-11`、`g++-11`。

------

#### 2. 添加 PPA 源

```
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
```

------

#### 3. 安装 gcc-13 和 g++-13

```
sudo apt install gcc-13
sudo apt install g++-13
```

------

#### 4. 设置优先级

```
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-11 11
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-13 13
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-11 11
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-13 13
```

------

#### 5. 检查版本

```
gcc -v
g++ -v
```

------

#### 6. 国内 PPA 源加速

-   中科大代理 PPA 地址：`launchpad.proxy.ustclug.org`
-   修改 `/etc/apt/sources.list.d/` 下需要代理的仓库地址，将 `ppa.launchpad.net` 替换为 `launchpad.proxy.ustclug.org`，示例：

```
# deb https://ppa.launchpadcontent.net/ubuntu-toolchain-r/test/ubuntu/ jammy main
deb https://launchpad.proxy.ustclug.org/ubuntu-toolchain-r/test/ubuntu/ jammy main
# deb-src https://ppa.launchpadcontent.net/ubuntu-toolchain-r/test/ubuntu/ jammy main
```

-   更新仓库并安装软件：

```
sudo apt update
sudo apt install <package_name>
```

------

#### 7. 安装 libc++ 开发库

```
sudo apt install libc++-dev libc++abi-dev
```

------

#### 8. VSCode 配置

1.  下载最新 clangd 压缩包并解压，将 `clangd` 放到 `/usr/local/bin`。
2.  clang-tidy 可通过 `pip install clang-tidy` 安装。
3.  修改 PATH 并添加到 `~/.bashrc`。
4.  编译标志配置：

```
CompileFlags:
  Add: [-xc++, -std=c++20]
```
