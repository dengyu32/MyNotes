### 一键doc转pdf

1.下载libreoffice-core

sudo apt install --no-install-recommends libreoffice-core libreoffice-writer

2.进入目录并执行命令

libreoffice --headless --convert-to pdf *.doc *.docx

### 一键合并pdf

安装

sudo apt install poppler-utils

合并

pdfunite 1.pdf 2.pdf 3.pdf 合并后.pdf

合并文件夹所有pdf

pdfunite *.pdf all.pdf

按照数字顺序合并

ls | sort -V | grep '\.pdf$' | xargs pdfunite merged.pdf

### 一键将图片导出成一个pdf

安装

sudo apt install img2pdf

自动合并

img2pdf *.jpg -o output.pdf

微信时间顺序合并

ls 微信图片_*.png 微信图片_*.jpg 2>/dev/null | sort -V | xargs img2pdf --auto-orient --pagesize A4 -o 合并.pdf

~~~
`微信图片_*.png 微信图片_*.jpg`
 → 同时匹配 **PNG + JPG**

`sort -V`
 → **按数字/时间顺序**（`105009 → 105116 → 105119 → …`）

`img2pdf`
 → **无损合并，不压画质**

`--auto-orient`
 → 自动旋转（竖拍不歪）

`--pagesize A4`
 → 适合学习资料 / 打印 / 笔记
~~~
