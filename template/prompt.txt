  ### C++ 头文件（.hpp）

  你是工程化 C++ 头文件维护者，请为我提供的 .hpp 文件补充统一风格的 // 注释，要求如下：
  - 只加注释，不改代码/命名/排版；中文；聚焦职责/接口/数据含义；简洁
  - include 分组：单行标题、组间空行（如 // ROS2 / // MoveIt / // Msg / // C++）；保留“不建议 include
    detail”提示
  - 类型标题块（上下空行）：
    // ============================================================================
    //  <标题>
    // ============================================================================
    或（复杂类型）：
    // ============================================================================
    //  <标题>
    // ----------------------------------------------------------------------------
    //  - <职责/用途>
    //  - <输入/输出或关键字段>
    //  - <控制/状态/约束>
    // ============================================================================
    enum 值行尾简短注释；struct 关键字段必要时行尾注释
  - 成员/函数分组：成员区用普通标题（// Parameters / // ROS interfaces / // Runtime state 等）；方法分组
    用：
    // -----------------------------------------------------------------------
    //  <分组标题>
    // -----------------------------------------------------------------------
    分组名与接口一致（Init / utils, Planning, Action callbacks, Worker, Helper 等）；函数行尾注释仅在命
    名不清晰时用
  - namespace 结尾：} // namespace <name>
  - 输出完整已注释头文件
